# AddrLib Analysis

This directory contains the functional analysis of AMD GFX10 AddrLib.

## Planned topics

1. Surface/tile address decomposition
2. GFX10 64KB tiling
3. Swizzle modes
4. Pipe selection
5. Bank selection
6. XOR/hash functions
7. DCC/HTILE-related address calculations
8. Conversion from software algorithm to combinational Verilog

Each topic should identify the relevant upstream function, derive the equations, and provide concrete bit-level examples where possible.
