# 项目上下文

## 当前状态

项目用于研究 AddrLib 地址计算。ADDRLIB.md 为主文档，case/ 保存计算用例；两者均已获用户确认，具体可信文件及字节基准见 TRUSTED_BASELINE.json。

现阶段完成了资料整理与版本管理，尚未完成算法复算或端到端 RTL 验证。文件哈希一致仅证明字节未变，不证明算法正确；不同用例引用不同源哈希，也不能单凭此判断用例错误。

## 目录与使用范围

- ADDRLIB.md、case/：日常研究依据，用例导航见 case/README.md。
- docs/：当前上下文、可信清单和精简工作记录。
- scripts/：项目维护与校验脚本。
- backup/：历史备份，默认不读取、不作为依据、不主动复核。

新增 case 按已有最大编号加 1，文件名格式和协作要求见根目录 AGENTS.md。

本地 Git 使用 main 分支，尚未配置远程。原始资料及变更过程可通过 Git 追溯；上下文只保留影响后续工作的事实、规则和未解决事项。
