# Verilog Models

This directory currently contains planning documentation only. ADDRLIB.md at the repository root is a preserved pseudo-RTL excerpt with missing declarations and syntax inconsistencies; it has not been compiled or verified as a complete hardware model.

Future models should state the exact GFX generation, supported swizzle/resource configurations and interface units, then validate against a pinned software reference. Register staging can be reorganized after functional equivalence is established.
